The platform has three pillars

Each one is a real artifact with real tests, not a roadmap bullet point.

🌐

The Gateway

Dependency-free, OpenAI-compatible. Mock, ollama, and OpenRouter providers behind one API — your keys, your models, everywhere. Streaming, CORS, and keyless local trust.

📐

AICS

The AgentForge Context Specification — a portable, filesystem-anchored project context that humans and AI tools both read. constitution, charter, ADRs, RFCs, agents — open and inspectable.

🛠️

The CLI

Validate, scaffold, explain, and diagnose AICS contexts from the terminal — validate-context, init-context, explain-context, doctor. The same checks run in CI on every push.

One API. Any provider.

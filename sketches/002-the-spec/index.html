Three engineering artifacts.

Each pillar ships as a real module with real tests, not a roadmap bullet.

MODULE 01

The Gateway

Dependency-free Python stdlib HTTP service, OpenAI-compatible. Mock, ollama, and OpenRouter providers behind one API — streaming, CORS, keyless local trust.

MODULE 02

AICS

The AgentForge Context Specification — a portable, filesystem-anchored project context that humans and AI tools both read. constitution, charter, ADRs, RFCs, agents.

MODULE 03

The CLI

Validate, scaffold, explain, and diagnose AICS contexts from the terminal — validate-context, init-context, explain-context, doctor. Same checks CI runs.

One API. Any provider.

The vendor-neutral promise, structured as a spec-compliance diagram.
